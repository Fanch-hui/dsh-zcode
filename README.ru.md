# DSH ZCode

**[简体中文](README.md) | [English](README.en.md) | Русский**

Подключает подписки ZCode к DeepSeek Harness через обратный прокси; поддерживаются модели BigModel и Z.AI по тарифам Coding Plan и Start Plan.

Плагин предоставляет интерфейс подключения и использования:

- В разделе «Плагины → ZCode» выберите платформу и тариф, войдите через веб-страницу (Coding Plan также принимает ключ тарифа вручную) и смотрите использование тарифа.
- После входа выберите модель нужного тарифа в переключателе моделей DSH.
- В настройках плагина можно изменить платформу и тариф по умолчанию, параллельность, лимит вывода, тайм-аут запроса и интенсивность размышлений.
- «Статистика токенов» показывает накопленные входные, выходные токены, чтение из кэша и процент попаданий для каждой модели каждого тарифа.

Установка — из [npm](https://www.npmjs.com/package/dsh-zcode) или [GitHub Releases](https://github.com/Fanch-hui/dsh-zcode/releases); установка, CLI, headless и разработка описаны в [docs/usage.ru.md](https://github.com/Fanch-hui/dsh-zcode/blob/main/docs/usage.ru.md).
